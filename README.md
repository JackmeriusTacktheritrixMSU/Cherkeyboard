# Cherkeyboard
A custom keyboard with an existing board PCB. It seems like there are easy to find ways to manufacture or buy most parts of a keyboard, except for the PCB. I decided to reuse an old Reddragon k552 PCB and build an awesome custom keyboard which you can add modules onto later. I plan to build a beat pad module, or maybe a volume slider.


**What's Custom?**

You can make any number of parts custom- even the PCB.

In this repo, I made everything except the PCB and the switches and keycaps custom. I redesigned a new plate, 3D Printed a case, and I'll be wiring some boards inside to turn the whole device into a USB hub so I can add my extra modules on later.

**The Plate**
I am going to use 1/8 inch acrylic here because the color was cool. The original keyboard is metal. Acrylic or plastic should work but make sure to make it thicker. I bought an acrylic sheet that wasn't quite big enough, so the cut is in two parts and the case accounts for that. If you cut the plate as one piece, you don't need to do this. <img width="1275" height="552" alt="image" src="https://github.com/user-attachments/assets/434e26b8-848b-4ac5-b22e-ee7047b07326" />

I will laser cut mine


**The Case**
The case in this repo is best 3D Printed. You'll need a special printer- in this case I'll use an Ender 5. It needs to have a hefty volume- the keyboard is 350mm long so make sure to account for that. The keyboard faces accomodate two 4 pin adafruit magnetic connectors and a USB C ch334f hub board
